# 🖋️ InkWell — Modern Blogging Platform

A beautiful, modern blogging platform built for writers who care about craft.

## ✨ Features

- 🎨 Beautiful typography with Playfair Display & Inter fonts
-  Dark/Light theme toggle
-  Fully responsive design
- ✍️ Immersive reading experience
-  Fast and optimized

## 🌐 Live Demo

**[Visit the Live Site](https://modern-blogging-plat-n7e8.bolt.host)**

## 🛠️ Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Framer Motion
- Supabase (Backend)
