## Database Schema (SQL Reference)

The following tables were created via Supabase migrations. This is the SQL equivalent of a Prisma schema.

### profiles
```sql
id            uuid  PK DEFAULT auth.uid() REFERENCES auth.users(id) ON DELETE CASCADE
email         text  NOT NULL
display_name  text  NOT NULL DEFAULT ''
bio           text  NOT NULL DEFAULT ''
avatar_url    text  NOT NULL DEFAULT ''
website       text  NOT NULL DEFAULT ''
created_at    timestamptz DEFAULT now()
updated_at    timestamptz DEFAULT now()
```
- 1:1 with `auth.users` — a trigger auto-creates a profile row on signup.

### posts
```sql
id                  uuid  PK DEFAULT gen_random_uuid()
author_id           uuid  NOT NULL DEFAULT auth.uid() REFERENCES profiles(id) ON DELETE CASCADE
title               text  NOT NULL
slug                text  NOT NULL  -- auto-generated by trigger, unique
excerpt             text  DEFAULT ''
content             text  DEFAULT ''  -- HTML from rich text editor
cover_image_url     text  DEFAULT ''
seo_title           text  DEFAULT ''
seo_description     text  DEFAULT ''
status              text  DEFAULT 'published'  -- 'draft' | 'published'
read_time_minutes   int   DEFAULT 1  -- auto-calculated by trigger
views_count         int   DEFAULT 0
deleted_at          timestamptz  -- soft delete (NULL = active)
created_at          timestamptz DEFAULT now()
updated_at          timestamptz DEFAULT now()
```
- Triggers: auto-generate slug from title, auto-calculate read time from content.

### tags
```sql
id          uuid  PK DEFAULT gen_random_uuid()
name        text  NOT NULL UNIQUE
slug        text  NOT NULL UNIQUE
created_at  timestamptz DEFAULT now()
```

### post_tags (join table)
```sql
post_id  uuid  REFERENCES posts(id) ON DELETE CASCADE
tag_id   uuid  REFERENCES tags(id) ON DELETE CASCADE
PRIMARY KEY (post_id, tag_id)
```

### comments
```sql
id                 uuid  PK DEFAULT gen_random_uuid()
post_id            uuid  NOT NULL REFERENCES posts(id) ON DELETE CASCADE
user_id            uuid  NOT NULL DEFAULT auth.uid() REFERENCES profiles(id) ON DELETE CASCADE
parent_comment_id  uuid  REFERENCES comments(id) ON DELETE CASCADE  -- NULL = top-level
content            text  NOT NULL
is_pinned          bool  DEFAULT false  -- post author can pin
is_deleted         bool  DEFAULT false  -- soft delete
created_at         timestamptz DEFAULT now()
updated_at         timestamptz DEFAULT now()
```
- Self-referencing FK enables threaded/nested replies.

### likes
```sql
user_id     uuid  NOT NULL DEFAULT auth.uid() REFERENCES profiles(id) ON DELETE CASCADE
post_id     uuid  NOT NULL REFERENCES posts(id) ON DELETE CASCADE
created_at  timestamptz DEFAULT now()
PRIMARY KEY (user_id, post_id)  -- one like per user per post
```

## Row-Level Security (RLS) Summary

| Table | SELECT | INSERT | UPDATE | DELETE |
|---|---|---|---|---|
| profiles | Public (all) | Authenticated (own only) | Authenticated (own only) | — |
| posts | Public (published+active) + author (own) | Authenticated (own) | Authenticated (own) | Authenticated (own) |
| tags | Public (all) | Authenticated (any) | — | — |
| post_tags | Public (all) | Authenticated (post author) | — | Authenticated (post author) |
| comments | Public (all) | Authenticated (own) | Authenticated (own) OR post author (pin) | Authenticated (own) OR post author (any) |
| likes | Public (all) | Authenticated (own) | — | Authenticated (own) |

## RESTful API Endpoints

### Authentication (handled by Supabase Auth client SDK)
| Method | Path | Description |
|---|---|---|
| — | Supabase SDK `signUp()` | Register with email/password |
| — | Supabase SDK `signInWithPassword()` | Login |
| — | Supabase SDK `signInWithOAuth('google')` | Google OAuth |
| — | Supabase SDK `signInWithOAuth('github')` | GitHub OAuth |
| — | Supabase SDK `signOut()` | Logout |
| — | Supabase SDK `onAuthStateChange()` | Session management |

### Posts
| Method | Path | Auth | Description |
|---|---|---|---|
| GET | `/api/posts` | Public | List posts (pagination, filter by tag/author, sort) |
| POST | `/api/posts` | Required | Create a new post |
| GET | `/api/posts/[id]` | Public* | Get single post by ID (*draft = author only) |
| PUT | `/api/posts/[id]` | Author | Update post |
| DELETE | `/api/posts/[id]` | Author | Soft-delete post |

### Comments
| Method | Path | Auth | Description |
|---|---|---|---|
| GET | `/api/posts/[id]/comments` | Public | List comments for a post (threaded) |
| POST | `/api/posts/[id]/comments` | Required | Create a comment (optionally reply to parent) |
| PUT | `/api/comments/[id]` | Owner/Author | Edit comment (owner) or pin/unpin (post author) |
| DELETE | `/api/comments/[id]` | Owner/Author | Delete comment (owner or post author) |

### Likes
| Method | Path | Auth | Description |
|---|---|---|---|
| GET | `/api/posts/[id]/likes` | Public | Get like count for a post |
| POST | `/api/posts/[id]/likes` | Required | Like a post |
| DELETE | `/api/posts/[id]/likes` | Required | Unlike a post |

### Tags
| Method | Path | Auth | Description |
|---|---|---|---|
| GET | `/api/tags` | Public | List all tags |

### Profile
| Method | Path | Auth | Description |
|---|---|---|---|
| GET | `/api/profile` | Required | Get current user's profile |
| PUT | `/api/profile` | Required | Update profile (display name, bio, avatar, website) |

## Standardized API Response Format

**Success:**
```json
{
  "data": { ... },
  "meta": { "page": 1, "perPage": 10, "total": 42 }
}
```

**Error:**
```json
{
  "error": {
    "code": "NOT_FOUND",
    "message": "Post not found"
  }
}
```

HTTP status codes: 200, 201, 204, 400, 401, 403, 404, 409, 500.
